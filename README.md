# UniCore - Your Personalized University Schedule

Website for Egyptian universities, starting with Benha University - 
Faculty of Computers and Artificial Intelligence.

Each student sees only HIS OWN schedule - by University, Faculty, Year, Group, Section.

## Problem

Students get confused by the general schedule.
Wrong hall, missed changes, and hard to find their own classes.

## Solution

UniCore shows a personalized schedule with:
Subject, Doctor / TA, Time, Place, Type (Lecture / Section / Lab)

## Features - 5 Pages

1. Landing / Selection Page
   Choose University, Faculty, Year, Group, Section -> Show My Schedule

2. Personal Schedule Page
   Your full week schedule + Filter: Today / Full Week

3. Search for Doctor / TA Page
   Search by professor name or subject

4. Faculty Guide Page
   Halls, Classrooms, Labs - Building, Floor, Map

5. Exams & Announcements Page
   Exam Schedule + Announcements like "Lecture Moved"
   + AI Assistant - Ask about your schedule

## Tech Stack

- Frontend: React + HTML + CSS
- Backend: Ready-made service (Firebase / Supabase) - Not built from scratch
- AI Assistant: Ready-made AI API - Not built from scratch
- Hosting: Vercel / Netlify
